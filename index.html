PhD Candidate

A graph-based framework for scientific workflows: modelling, abstraction, and visualisation for reuse

Supervisors

  • Sarah Cohen-Boulakia
  • Frédéric Lemoine

Summary

Over the past two decades, scientific workflows have become the preferred way to develop scientific analyses. In particular, they are designed to define highly reproducible analyses, while facilitating their development, execution, sharing and reuse. Recently, workflow systems like Nextflow and Snakemake have emerged as valuable tools for bioinformaticians with programming expertise. These systems offer flexible scripting languages that enable swift development and execution, enhancing their usability. Therefore, a growing number of workflows are available on online platforms such as GitHub and GitLab; these workflows can be heterogeneous and complex, thus hard to gain understanding. To improve reuse of scientific workflows, this PhD thesis proposes a framework to gain insight into them efficiently. To achieve this, the following tasks should be considered. (1) Describe workflows in a homogeneous graph-based way. (2) Bridge the gap between heterogeneous source code and homogeneous workflow graphs. (3) Define a manner to automatically simplify the workflow graphs, using elements inherently defined in the workflow. (4) Design a module capable of viewing the simplified graph at different simplification levels, using a visual standard already familiar to developers and linking the workflow logic to this visualisation.
